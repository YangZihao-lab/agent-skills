# Project Razor

项目断舍离与剃刀 Skill，用于减少软件项目中的重复入口、多重真相源、历史包袱和维护面。

## 默认行为

- 默认只读；
- 默认显式调用；
- 先审计和出计划；
- 只有用户明确批准精确动作清单后，才允许移动、合并、归档或删除；
- 不把功能开发与清理混在一起；
- 不删除证据、许可证、迁移历史和用户要求保留的本机状态。

## 调用

```text
$project-razor

对当前仓库执行 QUICK_RAZOR，只读，指出最影响理解的五个复杂度来源。
```

```text
$project-razor

生成文档、分支和工具的 CUT_PLAN，不做任何修改。
```

## 与分层治理的关系

`project-razor` 主要简化器、事、物层结构。需要改变项目方法论或战略时，应交给 `layered-thinking-governance` 对应的上级窗口裁决。
