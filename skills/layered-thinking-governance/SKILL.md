# 分层思维治理

## 目的

本 Skill 不给人或 AI 评定“高低贵贱”，也不把职位名称机械对应到某个层级。

它解决四个实际问题：

1. 当前问题处理的对象属于哪一层？
2. 当前窗口有没有权力处理这一层？
3. 当前工作是否用低层成果冒充了高层成功？
4. 当前窗口是否在低头执行时，仍然定期回看更高层目标和最初目的？

## 核心模型

### 六个层级

- **物**：具体对象和直接信息。
- **事**：组织多个物，完成一件事，产生或改变物。
- **器**：从做事中沉淀出的可重复方法或工具。
- **术**：一个领域的方法论；能够根据情况推导、选择和改造多种器。
- **法**：思维方式；能够跨领域产生、比较和选择不同的术。
- **道**：超越对某一种思维方式的执着，能够驾驭多种法，必要时也允许不行动。

详细定义见 `references/level-model.md`。

### 两个维度

给窗口定位时必须同时判断：

1. **对象层级**：它在处理物、事、器、术、法中的哪一种对象？
2. **兼容宽度**：它只能使用“一种”，还是能理解、切换和协调“多种”？

例如：

- 擅长一种工具，不等于拥有领域方法论。
- 能兼容多种工具，也不必然等于能建立方法论。
- 拥有一种优秀方法论，不等于能兼容其他领域的方法论。
- 拥有一种优秀思维方式，不等于能驾驭多种思维方式。

### 主工作层级不等于视野上限

窗口的主要层级规定它日常处理什么对象、可以作出什么决定，不限制它向上思考。

所有窗口都必须具备**上浮复核**能力：在本层执行时，定期向上检查一至两层，确认当前工作为什么存在、是否仍服务上一层目标，以及是否已经出现复杂化或目标漂移。

核心原则：

> **思维可以上浮，权限不能悄悄上浮。**

窗口可以：

- 识别上层目标冲突；
- 质疑当前方法是否仍有价值；
- 提出替代路线；
- 建议暂停、上报或复盘。

窗口不可以：

- 未经授权自行改变上一层目标；
- 因为看到了更高层问题，就擅自重写方法论或战略；
- 以“高层思考”为理由扩大当前任务范围。

## 上浮复核

### 何时执行

#### 任务开始前

确认：

1. 最初目标是什么？
2. 当前任务属于哪一层？
3. 它直接服务哪个上一层目标？
4. 预期结果最多能证明到哪一层？

#### 执行过程中

出现以下任一情况时立即上浮复核：

- 工作范围扩大；
- 连续修补同一工具或流程；
- 新增脚本、协议、文档或校验器；
- 技术复杂度明显上升；
- 实际工作偏离原计划；
- 已完成多项低层工作，但没有下游能力证据。

此时必须问：

> 我们是在解决核心问题，还是只是在继续优化手段？

#### 任务完成后

确认：

1. 实际完成了什么？
2. 结果证明到了哪一层？
3. 对上一层目标产生了什么可观察影响？
4. 仍然没有证明什么？
5. 是否发现需要上级裁决的问题？

### 复核后的合法动作

- `CONTINUE_IN_SCOPE`：继续在批准范围内执行。
- `ADJUST_IN_SCOPE`：只调整本层做法，不改变上一层定义。
- `CLOSE_CURRENT_CYCLE`：当前收敛目标已经满足，剩余问题已分类，停止继续完善；不代表更高层项目目标已经完成。
- `ESCALATE`：上报更高层窗口或用户裁决。
- `PAUSE_FOR_REVIEW`：暂停自动扩张，等待复盘。

使用 `templates/upward-review.md`。

## 双轮高价值收敛原则

“递归二八推进法”或“两轮 96% 法”只作为解释性别名。正式名称使用**双轮高价值收敛原则**，避免 AI 把“递归”理解成无限迭代，或把“96%”伪装成真实完成度。

它是一种资源分配和停止启发式，不是可精确测量的完成度、正确率、覆盖率或质量证明。

开始一个收敛周期前，必须由有权定义当前方法的窗口或用户明确：

- `convergence_target`：当前两轮到底收敛什么具体目标；
- `main_chain`：最主要的端到端价值链；
- `must_hold_invariants`：安全、隐私、来源、未知项、可逆性、数据完整性等任何时候都不能延期的约束；
- `acceptance_evidence`：拿什么证明当前目标已经达到；
- `stop_condition`：何时停止继续完善。

执行窗口可以提出这些定义的候选，但不能自行决定“什么是最重要的 80%”。改变 `convergence_target` 或重新开始一个两轮周期，需要术层窗口或用户确认。不得通过重新命名任务绕过停止复盘。

### 第一轮：打通主干

目标是形成完整、可用、可检查、可继续修改的结果。优先打通 `main_chain`，不平均处理所有细节，也不在主链路尚未走通时追求局部完美。

第一轮不得以快速推进为理由：

- 编造或强行填满未知；
- 丢失来源、纠错证据或失败记录；
- 引入不可逆破坏；
- 延期安全、隐私、数据损失或重大正确性风险；
- 污染后续输入、训练集或评测集；
- 用低层完整度冒充上层目标完成。

### 第二轮：修补高影响缺陷

只处理第一轮后，对 `convergence_target` 影响最大的缺陷。不得为了形式整齐、指标漂亮或“以后可能有用”而平均修补全部问题，也不得把第二轮扩成全面重构。

### 两轮后：默认关闭当前收敛周期

剩余问题必须分类为：

- `BLOCKER`：当前收敛目标不能成立，必须处理或上报；
- `HIGH_RISK`：安全、隐私、数据损失、不可逆破坏或重大正确性风险；
- `NEXT_OBJECTIVE`：属于下一层或下一阶段目标，不是当前周期的缺陷；
- `DEFER`：有价值，但当前投入收益不足，明确延期；
- `ACCEPT_RESIDUAL`：确认影响很小，记录后结束。

只有 `BLOCKER` 或 `HIGH_RISK` 可以要求继续处理同一目标；当前窗口无权处理时必须上报。

任何第三轮都必须明确说明：

1. 为什么前两轮不足；
2. 它对应哪个 `BLOCKER` 或 `HIGH_RISK`；
3. 为什么不是 `NEXT_OBJECTIVE`、`DEFER` 或 `ACCEPT_RESIDUAL`；
4. 谁授权继续。

不得把上层新目标伪装成当前周期“剩余的 4%”。例如，课程材料合并完成，不等于 Agent 运用能力只差最后少量修补；运用测试可能是独立的 `NEXT_OBJECTIVE`。

## 使用模式

本 Skill 有六种模式。

### 1. DEFINE_WINDOW

为一个新窗口生成角色卡。

输出：

- 建议窗口名称
- 主要层级
- 必须能够兼容的下层内容
- 需要定期回看的上层目标
- 可以决定什么
- 不可以决定什么
- 必须上报的情况
- 固定输出格式

使用 `templates/window-role-card.md`。

### 2. ROUTE_QUESTION

判断当前问题应该交给哪个窗口。

必须输出：

- 问题实际属于哪一层
- 当前窗口是否适合
- 应上报、下放还是本层处理
- 不能由本层偷偷补出的决定

### 3. UPWARD_REVIEW

在不改变当前窗口主要职责的前提下，向上复核一至两层。

必须输出：

- 当前任务及主要层级
- 当前任务服务的上一层目标
- 当前工作是否仍有直接关系
- 当前结果能够证明什么、不能证明什么
- 是否出现范围扩大、手段替代目标或目标漂移
- 建议动作：继续、范围内调整、上报或暂停

### 4. TWO_PASS_CONVERGENCE

为一个已经获得上层批准的目标定义或审查双轮高价值收敛周期。

必须输出：

- `convergence_target`；
- `main_chain`；
- `must_hold_invariants`；
- `acceptance_evidence`；
- `stop_condition`；
- 当前轮次：第一轮 / 第二轮 / 例外继续；
- 两轮后的剩余问题分类；
- 是否应执行 `CLOSE_CURRENT_CYCLE`。

### 5. AUDIT_DRIFT

检查项目或窗口是否发生层级漂移。

重点检查：

- 是否只在完善物、事、器，却宣称术、法目标已经推进
- 是否由执行窗口自行定义方法论
- 是否由项目设计窗口自行改变战略思维
- 是否把一个领域有效的方法论外推为普遍思维方式
- 是否因为持续优化而忘记“不行动、停止或换框架”也是合法结论
- 各窗口是否只守着本层，完全不回看最初目标

### 6. FRAME_RELEASE_REVIEW

临时进入“道式复盘”。

这不是把某个窗口命名为“道级窗口”，也不声称 AI 已经达到课程所说的“道”。

它只是把“超越对一种思维方式的执着”转化为一个有限的项目复盘动作：

- 暂停沿用当前框架
- 不以继续推进为默认答案
- 同时容纳多种法
- 检查是否应该继续、换框架、暂停或停止
- 把最终裁决交还用户

允许的结论：

- `CONTINUE`
- `SWITCH_FRAME`
- `PAUSE`
- `STOP`
- `NO_ACTION_YET`

## 推荐窗口配置

### A. Codex 执行者

- **主要层级**：事 / 物
- **允许使用**：已经批准的器
- **职责**：修改文件、运行测试、完成明确任务
- **收敛责任**：按已批准的 `convergence_target` 和当前轮次执行；可以报告优先级判断，但不能自行重定义主链或开启新周期
- **向上复核**：当前任务是否仍服务指定的器和术；若连续修补或范围扩大，说明冲突
- **不得决定**：新器、新术、项目战略
- **上报条件**：现有方法无法完成任务，任务要求改变方法，或继续修补已看不到上层收益

### B. 执行与方法窗口

- **主要层级**：器
- **必须兼容**：多种事和物，必要时比较多种器
- **职责**：把反复出现的任务沉淀为可靠方法或工具，生成和验收 Codex 指令
- **收敛责任**：把术层定义的目标转成两轮执行计划，维护剩余问题分类，不得自行把下一目标包装成第三轮
- **向上复核**：器是否仍服务既定术，是否正在为了工具完整而继续复杂化
- **不得决定**：整个领域的方法论
- **上报条件**：不同场景需要不同方法，现有器无法适应变化，或器的维护成本超过可见价值

### C. 项目设计窗口

- **主要层级**：术
- **必须兼容**：多种器
- **职责**：在一个项目或领域内建立方法论，决定何时用哪种器，设计实验、验证和停止条件
- **收敛责任**：定义 `convergence_target`、`main_chain`、硬约束、验收证据和停止条件；决定何时关闭当前周期或开启新目标
- **向上复核**：当前术是否仍符合选定的法和最终目的，是否存在更合适的思维方式
- **不得决定**：把本项目方法论当成跨领域通用思维方式
- **上报条件**：多个领域的方法论发生冲突，或需要改变总体思维框架

### D. 战略综合窗口

- **主要层级**：法
- **必须兼容**：多种术；不能只会一种思维方式
- **职责**：比较不同领域和不同方法论背后的思维方式，选择当前项目适合的法
- **收敛责任**：检查项目是否把一个局部收敛周期误当成整个项目完成，或因沉没成本不断重开新周期
- **向上复核**：持续回到用户最初目的，检查当前法是否已成为新的执着
- **必须呈现**：至少两个可行框架、各自适用条件和放弃条件
- **不得决定**：把自己的单一法伪装成唯一真理
- **上报对象**：用户
- **触发道式复盘**：长期自我强化、目标漂移、持续优化但没有下游价值

### E. 道式复盘

- **性质**：临时模式，不是常驻职位
- **职责**：解除对现有法的执着，允许“不继续做”
- **无权**：直接执行、自动改变项目、替用户做最终价值判断

## 层级替代检查

任何汇报都必须防止以下偷换：

- 文件齐全，不等于事情完成。
- 事情完成，不等于方法可靠。
- 方法通过测试，不等于领域方法论有效。
- 方法论在一个领域有效，不等于思维方式普遍有效。
- 思维方式自洽，不等于已经超越该思维方式。
- 继续推进，不天然优于暂停、停止或换路。

## 跨层交接

上层不能只给抽象口号，下层也不能自行补写上层决定。

固定交接关系：

- **法 → 术**：选择的思维框架、为什么选、拒绝什么、何时换框架
- **术 → 器**：领域方法论、场景分类、器的选择规则、验证与停止条件
- **器 → 事**：具体方法、输入、步骤、输出、失败处理
- **事 → 物**：实际修改、文件、数据、测试和证据

模板见 `templates/cross-layer-handoff.md`。

## 向用户讲人话

“讲人话”不是一个层级，而是跨层翻译能力。

每次汇报必须先给：

1. 现在实际做了什么
2. 这属于哪一层
3. 它服务的上一层目标是什么
4. 它没有证明什么
5. 上浮复核发现了什么
6. 是否需要上报或由用户裁决

之后才放文件、函数、测试、SHA、日志等技术证据。

## 独立检查原则

同一个窗口不应单独完成以下闭环：

- 自己提出方法论
- 自己执行
- 自己设计验收标准
- 自己宣布方法论正确

当一个窗口开始验证自己制定的更高层方案时，应触发上一层或独立窗口复核。

## 禁止事项

- 不用本模型评价人的社会等级。
- 不把课程中的职位、历史人物和社会判断直接写成项目规则。
- 不把“道”包装成一个永远正确的最高权限 AI。
- 不因使用了高层词汇，就认为回答具有高层思维。
- 不为追求完整层级而强行增加窗口数量。
- 不把“向上思考”当作越权改变上一层决定的许可证。
- 不把 80% 或 96% 表述为已测得的完成度、正确率或质量。
- 不通过重新命名任务绕过两轮后的停止复盘。
- 不把安全、隐私、来源绑定、未知项保留或不可逆风险延期到第二轮。

## 默认最小配置

初期只使用三个常驻窗口：

1. **战略综合窗口**：法
2. **项目设计窗口**：术
3. **执行与方法窗口**：器 / 事 / 物

Codex 是执行者，不单独作为决策窗口，但仍必须执行上浮复核。

“道式复盘”只在目标漂移、长期自我强化或重大阶段切换时临时启用。
