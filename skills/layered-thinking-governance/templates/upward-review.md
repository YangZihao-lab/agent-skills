# 上浮复核模板

> 用于任何窗口。主工作层级不变，只临时向上检查一至两层。

## 1. 当前定位

- **当前任务：**
- **主要层级：** 物 / 事 / 器 / 术 / 法
- **直接服务的上一层目标：**
- **用户最初目的：**

## 2. 当前收敛周期

- **convergence_target：**
- **当前轮次：** 第一轮 / 第二轮 / 例外继续 / 未定义
- **main_chain：**
- **must_hold_invariants：**
- **acceptance_evidence：**
- **stop_condition：**
- **本窗口是否有权定义或改变以上内容：** 是 / 否

如果目标尚未由有权窗口或用户确认，本窗口只能提出候选，不得自行开始或重开两轮周期。

## 3. 开始前检查

- 为什么现在要做这件事？
- 它和上一层目标的直接关系是什么？
- 预期结果最多能证明到哪一层？
- 哪些更高层结论即使完成也不能推出？
- 当前停止条件是什么？

## 4. 过程中检查

是否出现：

- [ ] 范围扩大
- [ ] 连续修补
- [ ] 新增工具、协议、文档或治理结构
- [ ] 技术复杂度明显上升
- [ ] 实际工作偏离原计划
- [ ] 低层指标改善，但没有下游能力证据
- [ ] 当前窗口开始替上一层作决定

如果勾选任一项，回答：

> 我们是在解决核心问题，还是只是在继续优化手段？

## 5. 完成后检查

- 实际完成了什么？
- 结果证明到了哪一层？
- 对上一层目标产生了什么可观察影响？
- 仍然没有证明什么？
- 有没有出现目标漂移、复杂化或沉没成本影响？

## 6. 两轮后复核

- **剩余 BLOCKER：**
- **剩余 HIGH_RISK：**
- **属于 NEXT_OBJECTIVE 的事项：**
- **明确 DEFER 的事项：**
- **ACCEPT_RESIDUAL 及理由：**
- **如果继续第三轮，对应的阻断/高风险、授权人和必要性：**
- **是否应关闭当前周期：** 是 / 否

## 7. 权限检查

- 我可以在本层直接调整什么？
- 哪些变化需要上报？
- 我是否正在以“高层思考”为理由扩大执行权限？

## 8. 建议动作

只能选择一种主动作：

- `CONTINUE_IN_SCOPE`：继续在原批准范围内。
- `ADJUST_IN_SCOPE`：只调整本层做法。
- `CLOSE_CURRENT_CYCLE`：当前目标已满足，剩余问题已分类，停止继续完善。
- `ESCALATE`：上报更高层窗口或用户。
- `PAUSE_FOR_REVIEW`：暂停自动扩张，等待复盘。

## 9. 人话版结论

用不超过五句话说明：

1. 现在在做什么；
2. 为什么做；
3. 证明了什么；
4. 没证明什么；
5. 是否需要上报或暂停。
