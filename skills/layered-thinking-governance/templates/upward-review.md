# 上浮复核模板

> 用于任何窗口。主工作层级不变，只临时向上检查一至两层。

## 1. 当前定位

- **当前任务：**
- **主要层级：** 物 / 事 / 器 / 术 / 法
- **直接服务的上一层目标：**
- **用户最初目的：**

## 2. 开始前检查

- 为什么现在要做这件事？
- 它和上一层目标的直接关系是什么？
- 预期结果最多能证明到哪一层？
- 哪些更高层结论即使完成也不能推出？
- 当前停止条件是什么？

## 3. 过程中检查

是否出现：

- [ ] 范围扩大
- [ ] 连续修补
- [ ] 新增工具、协议、文档或治理结构
- [ ] 技术复杂度明显上升
- [ ] 实际工作偏离原计划
- [ ] 低层指标改善，但没有下游能力证据
- [ ] 当前窗口开始替上一层作决定

如果勾选任一项，回答：

> 我们是在解决核心问题，还是只是在继续优化手段？

## 4. 完成后检查

- 实际完成了什么？
- 结果证明到了哪一层？
- 对上一层目标产生了什么可观察影响？
- 仍然没有证明什么？
- 有没有出现目标漂移、复杂化或沉没成本影响？

## 5. 权限检查

- 我可以在本层直接调整什么？
- 哪些变化需要上报？
- 我是否正在以“高层思考”为理由扩大执行权限？

## 6. 建议动作

只能选择一种主动作：

- `CONTINUE_IN_SCOPE`：继续在原批准范围内。
- `ADJUST_IN_SCOPE`：只调整本层做法。
- `ESCALATE`：上报更高层窗口或用户。
- `PAUSE_FOR_REVIEW`：暂停自动扩张，等待复盘。

## 7. 人话版结论

用不超过五句话说明：

1. 现在在做什么；
2. 为什么做；
3. 证明了什么；
4. 没证明什么；
5. 是否需要上报或暂停。
