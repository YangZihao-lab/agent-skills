# 分层思维治理 v0.2

这是根据用户提供的《思维的层级》《思维决定人的层级》重新设计的 Skill 草案。

与 v0.1 的主要区别：

1. 不再把“道”简单等同于最终目标或最高职位。
2. 不再只按窗口职位机械分配道、法、术。
3. 明确区分“处理对象的层级”和“能兼容一种还是多种”的宽度。
4. 将“道”仅转化为临时的框架超越复盘，不作为常驻 AI 权限。
5. 加入严格的层级替代检查，防止低层成功冒充高层成功。
6. `认知突破`只用于支持“当前思维难以独立发现自身局限，因此需要外部复核”这一原则。
7. 未使用“认知自我—认知社会”层级，也未使用道德层级。

- `references/level-model.md`：六层定义和“一/多”维度
